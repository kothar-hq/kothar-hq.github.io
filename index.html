Kothar

Hardened Windows Nano Server base images, done right.

Windows Server 2019, 2022, and 2025 container images built with the tools your workloads actually need. PowerShell and non-PowerShell variants of each.

  • Updated bsdtar & libarchive — ZIP and 7z support across all three versions
  • jq.exe for REST response parsing without PowerShell
  • curl.exe with HTTP/2 and HTTP/3 — features Microsoft doesn’t ship
  • edit.exe 2.0 — a familiar text editor when you need one in nano
